개인정보처리방침

시행일: 2026년 10월 6일

대상

studio-analytics는 운영자 본인이 소유한 YouTube 채널에만 사용하는 개인용 도구입니다. 다른 사람의 계정 정보를 받지 않습니다.

접근하는 정보

  • YouTube 채널 정보와 영상 목록(제목, 공개 상태, 길이)
  • YouTube Analytics 지표(조회수, 시청시간, 구독자 증감, 유입 경로, 노출수, 클릭률)
  • 업로드 권한: 운영자가 직접 지정한 영상과 썸네일만 업로드합니다. 기존 영상을 수정하거나 삭제하지 않습니다.

저장과 공유

가져온 데이터와 인증 토큰은 운영자의 컴퓨터에만 저장되며, 외부 서버로 보내거나 제3자와 공유하지 않습니다. 광고나 다른 목적으로 사용하지 않습니다.

권한 철회

Google 계정의 서드 파티 액세스 설정에서 언제든 권한을 철회할 수 있습니다. 철회하면 도구는 더 이상 데이터에 접근하지 못합니다.

Google API 서비스 사용자 데이터 정책

Google API에서 받은 정보의 사용은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
